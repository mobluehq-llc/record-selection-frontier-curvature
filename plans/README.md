# Frozen pre-registration texts and number manifest for "Record selection can mimic or mask acceleration in AI benchmarks"

Each file 01 to 12 is the text of a plan or amendment as committed, before the runs it governs, in the author's private archive; the hash in the file name is the commit that froze it. Apart from the redactions described below, the files are copies of the committed texts (extracted with `git show <commit>:<path>`), so they still contain working notes. Because the archive is not yet public, the SHA-256 of each file is listed so a reader can confirm that the copy they hold is the one deposited with the preprint.

Redactions: each span replaced by "[internal operations note redacted]" is an operational note (machine names, launch commands, local paths, internal process remarks). The redactions are operational only, and the originals (with their commit hashes) are available to referees on request. The SHA-256 list below is that of the redacted copies in this folder. File 13 is the manifest tying every number in the paper to its source file (the arXiv v2 build).
